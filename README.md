# MedGuide

**MedGuide** is a web application designed to make navigating the pharmacy easier, providing easy access to medical resources. 

This project is built using a full-stack TypeScript architecture, separated into a `frontend` and `backend`.

## 🚀 Project Structure

The repository is organized into the following main directories:

- **`/frontend`**: Contains the client-side application code.
- **`/backend`**: Contains the server-side API and logic.
- **`/PLAN.md`**: Project roadmap and planning documentation.
  
## 🛠️ Tech Stack

**Frontend (Mobile)**
- **Framework**: [React Native](https://reactnative.dev/)
- **Language**: TypeScript 

**Backend (API)**
- **Runtime**: [Node.js](https://nodejs.org/)
- **Framework**: [Express.js](https://expressjs.com/)
- **Database**: [MongoDB](https://www.mongodb.com/) (User profiles, surveys, logs)

**AI & Data Science**
- **Language**: Python
- **Frameworks**: Scikit Learn
